# Synthetic Repo 03

A small React + Vite + Tailwind login card used for dataset generation and UI alignment testing.

## Setup
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
4. Preview production build: `npm run preview`

## Notes
- App entry: `src/main.jsx`
- UI layout: `src/App.jsx`
- Styles via Tailwind: `src/index.css` with config in `tailwind.config.js`
